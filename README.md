# ExamDost 📚

## About the Project

ExamDost is an AI-powered study notes generator that turns any topic into structured, exam-ready notes. It uses Google's Gemini AI to generate content, renders it with auto-generated diagrams, and lets users export everything as a clean PDF — all backed by a credits-based usage system.

## Features

- 🤖 AI-generated, structured study notes on any topic
- 📊 Auto-generated diagrams using Mermaid.js
- 📄 Export notes as downloadable PDFs
- 🔐 Secure Google sign-in via Firebase Auth
- 💳 Credits system with Stripe-powered payments

## Tech Stack

- **Frontend & Backend:** MongoDB, Express.js, React, Node.js (MERN)
- **AI:** Google Gemini API (gemini-2.5-flash)
- **Authentication:** Firebase Google Authentication
- **Payments:** Stripe
- **PDF Generation:** PDFKit
- **Diagrams:** Mermaid.js

## How It Works

1. User signs in using Google Authentication.
2. User enters a topic for which they want study notes.
3. Gemini AI generates structured, exam-ready notes.
4. Mermaid.js generates diagrams where required.
5. Users can view and edit their generated notes.
6. Users can export their notes as a downloadable PDF.
7. The credits system manages AI usage, with additional credits available through Stripe payments.
